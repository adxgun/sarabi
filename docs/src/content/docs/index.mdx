## Next steps

<CardGrid stagger>
	<Card title="Language Agnostic" icon="seti:json">
		Deploy web applications written in any programming language with just a `Dockerfile`.
	</Card>
	<Card title="Full-Stack Deployment" icon="rocket">
		Supports deploying both service APIs and frontend (static files) in a single step.
	</Card>
	<Card title="Multi-Environment Support" icon="setting">
		Easily spin up multiple replicas of your app in different environments (e.g., `dev`, `prod`) with a single command.
	</Card>
	<Card title="Database Resource Provisioning" icon="seti:db">
		Built-in support for PostgreSQL, MySQL, MongoDB, and Redis.
	</Card>
    <Card title="Automatic Database Backups" icon="seti:db">
		Automatically backs up your database when you deploy an app with a database. Backups are stored on the server or can be configured to use S3-compatible object storage (recommended).
	</Card>
	<Card title="Automatic HTTPS" icon="setting">
		Powered by `Caddy` for seamless HTTPS setup.
	</Card>
	<Card title="Logs Management" icon="magnifier">
		Access application logs with customizable log retention timelines. CLI allows you to filter and view logs in real-time.
	</Card>
	<Card title="Multi-Application Management" icon="setting">
		Deploy and manage multiple applications on a single server.
	</Card>
